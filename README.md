# NV center ZPL at high pressure and high temperature

Author: Risei Abe (Institute of Science Tokyo)

This repository is the public entry point for work on the NV-center zero-phonon line under high pressure and high temperature.

The working repository that contains this project is
[ultra-high-pressure-ODMR](https://github.com/Risei412/ultra-high-pressure-ODMR).
That repository is currently private, so the code and manuscripts live there.
