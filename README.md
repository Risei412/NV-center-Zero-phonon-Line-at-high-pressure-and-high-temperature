# NV center ZPL at high pressure and high temperature

Author: Risei Abe (Institute of Science Tokyo)

This repository is a landing page for work on the NV-center zero-phonon line under high pressure
and high temperature.

The code, tests and manuscripts live in the working repository,
[ultra-high-pressure-ODMR](https://github.com/Risei412/ultra-high-pressure-ODMR),
which is **public and MIT-licensed**. Read that one: it holds the frozen numerical model, its
reproduction of six published sources, and the 243 tests that pin it in CI.

## Links

- Working repository: https://github.com/Risei412/ultra-high-pressure-ODMR
- Researchmap: https://researchmap.jp/risei-abe

# 高圧・高温下における NV センターのゼロフォノン線
